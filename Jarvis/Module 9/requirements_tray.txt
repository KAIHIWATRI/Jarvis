# ─────────────────────────────────────────────
# Windows startup methods (tried in order)
# ─────────────────────────────────────────────
# 1. HKCU\Software\Microsoft\Windows\CurrentVersion\Run   (registry)
# 2. Task Scheduler (schtasks /create /sc ONLOGON)
# 3. %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\JARVIS.bat

# ─────────────────────────────────────────────
# File structure
# ─────────────────────────────────────────────
# jarvis_tray/
# ├── tray_service.py          ← entry point / orchestrator
# ├── tray_icon.py             ← pystray icon + animated frames + menu
# ├── background_service.py    ← asyncio task runner + hotkey + watchdog
# ├── startup_manager.py       ← Windows registry / Task Scheduler
# ├── service_state.py         ← state machine (IDLE→RUNNING→STOPPED)
# ├── shutdown_coordinator.py  ← safe ordered teardown with watchdog
# └── requirements_tray.txt    ← this file
